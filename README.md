# Polyvinyl-Chloride
TWSE (臺灣證券交易所) 的 PVC 「Permanent Virtual Circuit (永久虛擬電路)」連線程式

參考資料： 
- O-101-A10 TWSE主機連線作業手冊
- O-105-A10 TCPIP網路主機連線電腦作業手冊

# 實體線路架構

| Socket ID  | Source Port Number | 執行功能 | 
| :----: | :-----: |   :-----:   |
|   01   |  21XX1  | 檔案傳輸 (傳送) |
|   02   |  21XX2  | 檔案傳輸 (接收) |
|   03   |  21XX3  |   成交回報   |
|   04   |  21XX4  |     委託     |
|   05   |  21XX5  |     委託     |
|   06   |  21XX6  |     委託     |
|   07   |  21XX7  |     委託     |
|   08   |  21XX8  |     委託     |
|   09   |  21XX9  |     委託     |

`Source Port Number`與各功能的關係：21XX1為`檔案傳輸 (傳送)`、21XX2為`檔案傳輸 (接收)`、21XX3為`成交回報`、21XX4~21XX9為`委託`下單。`XX為二位數字識別碼`，詳細規定請參考「`申請競價設備連線及異動作業`」作業手冊第四章。

<br>

- 歷史淵源  
    > `TCPIP網路主機連線電腦作業手冊`中提到：「為方便證券商能以目前世界上最普遍使用的TCP/IP網路與臺灣證券交易所進行各項業務，臺灣證券交易所制定以TCP/IP網路為基礎的主機連線作業規範，並延續原以`X.25`網路為基礎的『`臺灣證券交易所主機連線作業手冊`』的精神與原則，繼續提供標準、開放及安全的連線作業環境。」

# Socket Level Message (SLM)

```python
+------------------------------------------------+----------------+--------------+
|                    Header                      |     [Body]     |   Trailer    |
+-------------+--------------+-------------------+----------------+--------------+
| Header Code | Control Code | AP-Message Length |     Payload    | Trailer code |
+-------------+--------------+-------------------+----------------+--------------+
| 2 bytes     | 2 bytes      | 2 bytes           | variable (0~N) | 2 bytes      |
+-------------+--------------+-------------------+----------------+--------------+
| 0xFEFE      | ASCII '10'   | payloadLen        |  payload bytes | 0xEFEF       |
+-------------+--------------+-------------------+----------------+--------------+
```

> 交易所應該還是大型主機，`AP-Message Length` 解碼都用 `BigEndian`。

| 欄位名稱 | 長度 | 說明 |
| :---------------: | :---: | :--------------------- |
| Header Code       | X(02) | 固定值 0xFEFE (2 bytes) |
| Control Code      | X(02) | ASCII, 2 bytes (如 "10") |
| AP-Message Length | Binary (2 bytes) | 2-byte unsigned integer, 表示 payload 長度 |
| Payload           | -- | 可為 null 或 variable 長度 (0 ~ MaxPacketSize) |
| Trailer code      | X(02) | 固定值 0xEFEF (2 bytes) |

# 軟體架構
- 連線子系統：提供`連線`及`離線`的功能
- 單筆訊息與檔案傳輸系統：提供`檔案傳輸`及`單筆訊息傳輸`的功能
- 其餘應用軟體：提供`委託輸入`、`成交回報`、`結算`、`投資人管理`、`交易報表`及`成交回報補送`之功能

## 連線子系統
連線子系統（`LINK SUBSYSTEM`) 提供應用子系統從離線狀態（`OFF LINE`）進入連線狀態（`ON LINE`），及從連線狀態進入離線狀態.在線上執行時各PVC均須先透過連線子系統檢核成功後，才能進入應用系統。
